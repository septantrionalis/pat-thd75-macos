# Third-party components

This project supplies integration scripts, example configurations, a small
radio-link reset helper, and a local source-adaptation script. Dependencies
must be obtained separately; no third-party executable or complete source
package is intended for inclusion in this repository.

- **Pat:** https://github.com/la5nta/pat — tested version 1.0.0.
- **tncd:** https://github.com/ben-kuhn/tncd — tested version 1.103-Beta.
  Download the matching macOS release and follow its upstream license/terms.
- **AX25Toolkit:** https://github.com/solariun/AX25Toolkit — pinned revision
  `943d1cc6e2313d339d13dc1fc317d6aea7930fee`. No license file or declared GitHub
  license was found when this project was prepared. Its source and built
  executable are excluded from Git. Obtain upstream clarification before
  redistributing that code or modified binaries. The local adaptation has
  not been submitted or accepted upstream.

All upstream authors retain their rights. This project does not grant rights
to third-party components. Before choosing a license for a public release,
review the contribution and dependency licensing; no repository-wide license
has been selected here on the owner's behalf.

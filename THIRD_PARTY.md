# Third-party components

This project supplies integration scripts, example configurations, a small
radio-link reset helper, and a local source-adaptation script. Dependencies must generally be obtained separately. At the owner's explicit
request, bin/bt_kiss_bridge is included as an exception; its provenance is
recorded in bin/README.md. Inclusion does not establish redistribution rights.

- **Pat:** https://github.com/la5nta/pat — tested version 1.0.0.
- **tncd:** https://github.com/ben-kuhn/tncd — tested version 1.103-Beta.
  Download the matching macOS release and follow its upstream license/terms.
- **AX25Toolkit:** https://github.com/solariun/AX25Toolkit — pinned revision
  `943d1cc6e2313d339d13dc1fc317d6aea7930fee`. No license file or declared GitHub
  license was found when this project was prepared. Its complete source is excluded from Git. A locally built ARM64 executable
  is included at the owner's request. Obtain upstream clarification before
  redistributing that code or modified binaries. The local adaptation has
  not been submitted or accepted upstream.
